# 🐍 NeonSnake

A neon-styled Snake game built with HTML, CSS, and JavaScript.

## Features

- 🎮 Classic Snake gameplay
- ⚡ Power-ups
- 🎨 Multiple skins and themes
- 🗺️ Different maps
- 🏆 Leaderboard
- 📈 Score and level system
- 📱 Responsive design
